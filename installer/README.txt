VetroLook
Version 1.0.1
Windows 10/11 x64

Fast native image viewer and photo library for Windows.

## INSTALLATION

Run:
VetroLook_Setup.exe

The installer will:

- install VetroLook
- register supported image formats
- add VetroLook to "Open with"
- create the uninstaller
- optionally create Start Menu/Desktop shortcuts

## UNINSTALLATION

Use:
Settings → Apps → Installed apps → VetroLook → Uninstall

or run the uninstaller from the VetroLook installation directory.

## SUPPORTED FORMATS

JPEG, PNG, WebP, AVIF, GIF, BMP, TIFF, HEIC/HEIF,
EXR, RAW formats supported by LibRaw, etc.

## PORTABLE USE

If you downloaded the Portable build, no installation is required.
Extract the archive and run VetroLook.exe.

## NOTES

- Some HEIC/HEIF formats may depend on installed Windows codecs.
- JPEG XL is not included in version 1.0.1.
- RAW decoding support depends on camera/file compatibility.
- Initial Gallery indexing may take some time on very large libraries.
- VetroLook does not upload your photo library to the cloud.

## DATA

VetroLook stores its index, settings and thumbnail cache locally.
Removing the application may not automatically remove user-created
settings/cache unless selected during uninstall.
